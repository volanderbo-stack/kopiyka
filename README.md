# 🪙 Копійка

Простий особистий фінансовий трекер для телефона. Записуй витрати й доходи, став ліміти на категорії, стеж за підписками та накопичуй на цілі.

**Відкрити:** https://volanderbo-stack.github.io/kopiyka/

- працює без інтернету;
- без реєстрації й без реклами;
- усі дані зберігаються **тільки на твоєму пристрої**.

## Що вміє

- **Записи.** Витрати й доходи за категоріями, з датою й коментарем. Тап на запис — редагувати або видалити.
- **Три валюти: ₴, $ і €.** Курс вводиш вручну в налаштуваннях. Кожен запис запам'ятовує курс на момент створення, тому старі записи не «пливуть», коли курс змінюється. У списку видно `−10 $ (≈ 415 ₴)`.
- **Головна.** Скільки лишилось за місяць, доходи й витрати, полоска загального бюджету, найближча підписка й останні 10 записів.
- **Бюджет.** Ліміт на кожну категорію. Полоска зелена до 80%, жовта до 100%, червона, коли перевищено.
- **Підписки.** Щомісячні й щорічні, у ₴, $ або €. Під кожною видно, скільки вона коштує за рік. Видно, через скільки днів списання (за 3 дні — жовтим), і скільки всі підписки коштують на місяць і на рік. Підписку, яку оплачує хтось інший, можна не рахувати в загальному підсумку. Дата списання сама переходить на наступний період.
- **Цілі.** Прогрес накопичення, поповнення й зняття. Якщо є дедлайн — підказка, скільки відкладати щомісяця.
- **Статистика.** Кругова діаграма витрат за категоріями з перемиканням місяців.
- **Початок місяця.** Якщо стипендія чи зарплата приходить, наприклад, 25-го — місяць можна рахувати з 25-го.
- **Бекап.** Експорт і імпорт усіх даних одним JSON-файлом. Якщо бекапу давно не було — Копійка нагадає.

## Як встановити на телефон

**Android (Chrome):**
1. Відкрий https://volanderbo-stack.github.io/kopiyka/
2. Меню ⋮ → **«Додати на головний екран»** (або **«Встановити застосунок»**).

**iPhone (Safari):**
1. Відкрий посилання саме в **Safari**.
2. Кнопка «Поділитися» (квадрат зі стрілкою) → **«На початковий екран»**.

Після цього Копійка відкривається з іконки як звичайний застосунок — без адресного рядка і без інтернету.

## Де зберігаються дані

Тільки в пам'яті браузера на твоєму телефоні (localStorage). Нічого не відправляється на сервер — сервера взагалі немає.

Це означає:
- якщо очистити дані браузера або видалити застосунок — записи зникнуть;
- на іншому телефоні твоїх записів не буде, поки не перенесеш їх через бекап.

## Як зробити бекап

1. ⚙️ Налаштування → **«Експорт даних»**. Збережеться файл `kopiyka-backup-РРРР-ММ-ДД.json`.
2. Збережи його в надійне місце: Google Диск, iCloud, Telegram «Збережене».
3. Щоб відновити: ⚙️ → **«Імпорт даних»** → вибери файл. Поточні дані будуть замінені даними з файлу.

## Для розробників

Чистий HTML, CSS і JavaScript — без фреймворків і без збірки.

| Файл | Що в ньому |
|---|---|
| `index.html` | розмітка: шапка, екрани, нижня панель, вікна |
| `style.css` | стилі, кольори в CSS-змінних у `:root` |
| `app.js` | уся логіка: дані, розрахунки, екрани, форми |
| `sw.js` | service worker для роботи офлайн |
| `manifest.json` | назва й іконки для встановлення на телефон |
| `TZ.md` | технічне завдання, за яким зроблено застосунок |

Запустити локально (потрібен Python):

```bash
python -m http.server 8080
```

і відкрити http://localhost:8080.

**Після зміни будь-якого файлу** збільш `CACHE_VERSION` у `sw.js` (наприклад, `kopiyka-v1.0.1`), інакше телефони ще довго показуватимуть стару версію з кешу.

Суми зберігаються цілими числами в копійках/центах (`12000` = 120,00), щоб не було помилок округлення.
