# Копійка — ТЗ для Claude Code

Як користуватись: одна частина = одна версія. Вставляй промпт у Claude Code цілком, чекай результат, перевір за чеклістом, роби коміт і тільки тоді переходь до наступної частини.

## Частина 1 — v0.1: каркас і навігація

```
Створи PWA-застосунок "Копійка" — особистий фінансовий трекер. Чистий HTML/CSS/JS, без фреймворків і без збірки, щоб працював на GitHub Pages. Весь інтерфейс українською.

Файли:
- index.html
- style.css
- app.js

Дизайн:
- Темна тема: фон #0F1115, картки #1A1D23, текст #F2F3F5, другорядний текст #8A8F98, акцент #3DDC97, помилка/перевищення #FF5C5C.
- Шрифт: системний (system-ui, -apple-system, "Segoe UI", Roboto, sans-serif).
- Мобільний формат: контент максимум 480px по центру, відступи 16px, кнопки не менше 44px у висоту.
- Кольори задай як CSS-змінні в :root.

Структура:
- Шапка: назва "Копійка" зліва, кнопка ⚙️ справа (відкриває екран Налаштування).
- <main> з секціями-екранами: home, budget, subscriptions, goals, stats, settings. Видно тільки один екран за раз.
- Нижня фіксована панель з 5 кнопками: 🏠 Головна, 📊 Бюджет, велика кругла кнопка ＋ по центру (акцентного кольору), 🔁 Підписки, 🎯 Цілі. Активна вкладка підсвічена акцентом.
- Кнопка ＋ поки що відкриває порожню нижню панель (bottom sheet) з заголовком "Новий запис" і кнопкою "Закрити".
- На кожному екрані поки заглушка: заголовок і текст "Тут буде …".

Логіка (app.js):
- Функція showScreen(name) перемикає екрани й підсвічує вкладку.
- Модуль збереження: один ключ localStorage "kopiyka-data".
  Структура за замовчуванням:
  {
    version: 1,
    transactions: [],
    categories: [
      {id:"food", name:"Їжа", icon:"🍔", limit:0},
      {id:"transport", name:"Транспорт", icon:"🚌", limit:0},
      {id:"study", name:"Навчання", icon:"📚", limit:0},
      {id:"fun", name:"Розваги", icon:"🎮", limit:0},
      {id:"clothes", name:"Одяг", icon:"👕", limit:0},
      {id:"health", name:"Здоров'я", icon:"💊", limit:0},
      {id:"subs", name:"Підписки", icon:"🔁", limit:0},
      {id:"other", name:"Інше", icon:"📦", limit:0}
    ],
    subscriptions: [],
    goals: [],
    settings: { currency: "UAH", monthStartDay: 1, rates: { USD: 41.5, EUR: 45 } }
  }
- Функції load() і save(). Якщо в localStorage нічого немає або там битий JSON, бери дані за замовчуванням і не падай.
- Усі суми зберігаються цілими числами в копійках/центах (12000 = 120.00).
- Допоміжна функція formatMoney(cents, currency) через Intl.NumberFormat("uk-UA", {style:"currency"}).

Код пиши простим, з короткими коментарями українською, щоб студент 1 курсу розумів.
```

## Частина 2 — v0.2: головні функції MVP

```
Продовжуємо застосунок "Копійка" (файли index.html, style.css, app.js вже є, дані в localStorage "kopiyka-data", суми в копійках). Реалізуй головні функції. Нічого з уже зробленого не ламай.

1. Форма "＋" (нижня панель "Новий запис"):
   - Перемикач Витрата / Дохід (за замовчуванням Витрата).
   - Велике поле суми (inputmode="decimal", приймає кому й крапку).
   - Сітка категорій з іконками (для доходу категорії: Стипендія 🎓, Зарплата 💼, Подарунок 🎁, Інше 📦 — додай їх у дані як incomeCategories).
   - Дата (за замовчуванням сьогодні), коментар (необов'язково).
   - Кнопка "Зберегти": перевір, що сума > 0 і категорія вибрана, інакше підсвіти поле червоним. Запис: {id, type:"expense"|"income", amount, category, date:"YYYY-MM-DD", note}.
   - Цю ж форму використовуй для редагування існуючого запису (з кнопкою "Видалити" з підтвердженням confirm).

2. Головна:
   - Назва поточного місяця. Великими цифрами "Лишилось" = доходи − витрати за місяць. Під цим "+доходи" і "−витрати".
   - Полоска: скільки відсотків загального бюджету (сума лімітів категорій) вже витрачено. Якщо лімітів немає — полоску не показувати.
   - Плашка найближчої підписки: "🔔 Назва · дата · сума" (якщо підписки є).
   - Список останніх 10 записів: іконка, категорія, коментар, сума (витрати червоним з −, доходи зеленим з +). Тап — відкрити редагування.
   - Кнопка "Статистика →".
   - Місяць рахується з урахуванням settings.monthStartDay.

3. Бюджет:
   - Для кожної категорії витрат: іконка, назва, "витрачено / ліміт", полоска прогресу. Колір: зелений до 80%, жовтий (#F5C451) 80–100%, червоний понад 100%.
   - Тап на категорію — панель: змінити ліміт + список записів цієї категорії за місяць.
   - Внизу підсумок: "Разом витрачено X з Y".

4. Підписки:
   - Список: назва, сума, період (щомісяця/щороку), дата наступного списання, "через N днів" (якщо ≤3 днів — підсвітити жовтим).
   - Якщо дата списання вже минула — автоматично зсунь її на наступний період.
   - Внизу: "Разом X/міс · Y/рік" (річні підписки ділити на 12 для місячної суми).
   - Кнопка "＋ Підписка" і редагування/видалення по тапу. Поля: {id, name, amount, period:"month"|"year", nextDate}.

5. Цілі:
   - Картки: назва, прогрес-бар, "накопичено / ціль", відсоток. Поля: {id, name, target, saved, deadline (необов'язково)}.
   - Кнопка "Поповнити" — ввести суму, вона додається до saved. Можна і зняти (від'ємна сума), але saved не менше 0.
   - Коли ціль досягнута — показати "🎉 Ціль досягнута!".
   - "＋ Ціль", редагування й видалення.

6. Статистика:
   - Кругова діаграма витрат за категоріями за вибраний місяць. Намалюй її самостійно через SVG (без бібліотек). Під діаграмою легенда: іконка, назва, сума, відсоток.
   - Перемикач місяців ◀ Жовтень 2026 ▶.
   - Якщо витрат немає — текст "У цьому місяці витрат немає".

7. Налаштування:
   - Основна валюта: ₴ / $ / € (settings.currency). Всі суми в застосунку показуються в ній через formatMoney.
   - День початку місяця (1–28).
   - "Експорт даних" — скачати файл kopiyka-backup-YYYY-MM-DD.json.
   - "Імпорт даних" — вибрати JSON-файл, перевірити, що в ньому є transactions і settings, спитати підтвердження і замінити дані. Якщо файл битий — показати помилку, нічого не міняти.
   - "Видалити всі дані" — з подвійним підтвердженням.

Після кожної зміни даних викликай save() і перемалюй поточний екран.
```

**Як перевірити:**
- [ ] Додай 5–6 витрат у різних категоріях і 1 дохід: Головна правильно рахує «Лишилось»
- [ ] Відкрий запис, зміни суму, потім видали інший: цифри оновились
- [ ] Постав ліміт «Їжа» 500 і витрать 450, потім 600: полоска жовта, потім червона
- [ ] Додай місячну підписку на 99 і річну на 1200: внизу «199/міс · 2388/рік»
- [ ] Створи ціль на 1000, поповни на 1000: з'явилось 🎉
- [ ] Статистика: діаграма збігається з сумами, ◀ ▶ перемикає місяці
- [ ] Зміни валюту на $: усі суми показуються з $
- [ ] Експорт → Видалити всі дані → Імпорт того ж файлу: все повернулось
- [ ] Імпорт будь-якого не-JSON файлу: помилка, дані цілі
- [ ] Перезавантаж сторінку: усе на місці

## Частина 3 — v0.3: дизайн і дрібниці

```
Продовжуємо "Копійку". Додай покращення, нічого не ламаючи. Старі дані в localStorage мають і далі працювати (зроби міграцію: якщо в записі немає currency/rate — підстав основну валюту і rate = 1).

1. Валюта в кожному записі (без інтернету, курс вручну):
   - У формі "＋" біля суми маленький перемикач ₴ $ € (за замовчуванням основна валюта).
   - У Налаштуваннях поля "1 $ = __ ₴" і "1 € = __ ₴" (settings.rates).
   - Під час збереження запису додавай поля currency і rate — курс цієї валюти до основної на момент створення. Перерахунок: через гривню як базу (наприклад, USD→EUR = rates.USD / rates.EUR).
   - Баланс, бюджет, статистика рахують суми в основній валюті за збереженим rate запису (щоб старі записи не змінювались при зміні курсу).
   - У списку записів: "−10 $ (≈ 415 ₴)", якщо валюта запису не основна.

2. Перший запуск: якщо даних ще немає — екран привітання "Привіт! Це Копійка 👋", вибір основної валюти і кнопка "Почати".

3. Порожні стани з емодзі й підказкою на кожному екрані ("Ще немає записів — натисни ＋").

4. Анімації: нижня панель виїжджає знизу (transform + transition 250ms), плавна зміна ширини полосок прогресу, легкий відгук при натисканні кнопок (scale 0.97). Поважай prefers-reduced-motion.

5. Замість confirm() зроби власне модальне вікно підтвердження в стилі застосунку.

6. Нагадування про бекап: якщо останній експорт був понад 30 днів тому (зберігай settings.lastBackup) — на Головній плашка "💾 Давно не робив бекап" з кнопкою "Експорт" і хрестиком "Нагадати пізніше" (через 7 днів).

7. Цілі з дедлайном: підказка "Відкладай X/міс, щоб встигнути до <місяць>".

8. PWA:
   - manifest.json: name "Копійка", short_name "Копійка", theme_color і background_color #0F1115, display "standalone", start_url "./", іконки icons/icon-192.png і icons/icon-512.png (згенеруй прості іконки: зелена монетка ₴ на темному фоні, можна через SVG, перетворений у PNG через canvas-скрипт, або дай мені SVG і інструкцію).
   - sw.js: кешує всі файли застосунку, працює офлайн. Стратегія: спочатку кеш, у фоні оновлення. Версія кешу в константі, щоб легко оновлювати.
   - Зареєструй service worker в app.js. Усі шляхи відносні (./), бо сайт буде на github.io/kopiyka/.
   - meta theme-color, apple-touch-icon, apple-mobile-web-app-capable.
```

**Як перевірити:**
- [ ] Відкрий у режимі інкогніто: з'явився екран привітання
- [ ] Курс $ = 41.5. Додай витрату 10 $: у списку «−10 $ (≈ 415 ₴)», баланс зменшився на 415
- [ ] Зміни курс на 45: старий запис і далі ≈ 415 ₴
- [ ] Порожні екрани показують підказки
- [ ] Видалення відкриває гарне модальне вікно, а не системне
- [ ] DevTools → Application → Manifest: без помилок, іконки видно
- [ ] DevTools → Network → Offline, перезавантаж: застосунок відкривається
- [ ] На телефоні «Додати на головний екран»: відкривається без адресного рядка, з іконкою монетки
